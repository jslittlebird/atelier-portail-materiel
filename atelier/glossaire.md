# Glossaire

| Terme | En une phrase |
| --- | --- |
| LLM (grand modèle de langage) | Un programme qui prédit le morceau de texte le plus probable, encore et encore. |
| Token | Le morceau de texte que manipule le modèle : un mot, un bout de mot ou un signe. |
| Contexte (fenêtre de contexte) | Tout ce que le modèle « a sous les yeux » pendant l'échange : votre demande, les documents, l'historique. |
| Température | Le réglage qui rend les réponses plus prévisibles (bas) ou plus variées (haut). |
| Hallucination | Une information inventée mais présentée avec assurance. |
| Complaisance | La tendance du modèle à vous donner raison. |
| Projet Claude | Un espace qui garde des consignes et des documents pour un sujet qui revient. |
| Artefact | Un contenu produit à part par Claude : document, page, outil interactif. |
| Connecteur | Un branchement de Claude vers un outil (GitHub, Microsoft 365…). |
| MCP | Le standard qui permet de brancher l'IA sur des outils ; un « serveur MCP » expose un outil à Claude. |
| Skill | Une compétence réutilisable : des instructions que Claude applique quand c'est pertinent. |
| Plugin | Un paquet qui regroupe skills, commandes et connexions pour une équipe. |
| Cowork | Le mode où Claude travaille comme un agent sur vos fichiers et outils de bureau. |
| Claude Code | Le mode où Claude travaille comme un agent sur du code et des dépôts. |
| CLAUDE.md | Le fichier de règles du projet, lu par Claude Code à chaque session. |
| Plan mode | Le mode où Claude Code propose un plan sans rien modifier, en attendant votre feu vert. |
| Dépôt (repository) | Le dossier du projet versionné sur GitHub. |
| Issue | Un ticket GitHub : une story, un bug, une demande. |
| Branche | Une copie de travail du code, pour modifier sans toucher à la version principale. |
| Commit | Un enregistrement daté d'une modification. |
| Pull request (PR) | La proposition de fusionner une branche, avec relecture et tests. |
| CI (intégration continue) | Les vérifications automatiques lancées à chaque pull request. |
| Codespace | Un environnement de développement complet, ouvert dans le navigateur. |
| User story | Un besoin vu par son utilisateur : « En tant que…, je veux…, afin de… ». |
| Critère d'acceptation | Une condition vérifiable qui dit quand la story est terminée. |
| Epic | Un gros bloc fonctionnel, découpé en plusieurs stories. |
| Sprint | Une période courte et limitée dans le temps pour livrer un incrément. |
